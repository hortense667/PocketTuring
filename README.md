# Pocket Turing for M5Stack STOPWATCH
**〜 手のひらの上のデジタル虫かご（Digital Bug Box） 〜**

M5Stack STOPWATCH（ESP32-S3搭載）の円形ディスプレイ上で、**チューリングパターン（Gray-Scottモデル）**をリアルタイムにシミュレーションし、直感的なタッチ操作で模様を育て、採取し、再培養することができるインタラクティブ・ガジェットです。

![Pocket Turing Demo](images/demo.jpg) *(※ここに動作中の写真やGIFのURLを貼ってください)*

## ✨ 特徴 (Features)

* **爆速ハイブリッド・シミュレーション:** 
  ESP32-S3のデュアルコアを活用した並列処理、14ビット固定小数点演算と浮動小数点演算のハイブリッド処理、およびVRAMへのダイレクトアクセスにより、なめらかな模様の変化を実現しています。
* **直感的なパラメータ・チューニング (Touch Control):** 
  ディスプレイのフチを指でなぞることで、シミュレーションの「Feed（右フチ）」と「Kill（左フチ）」の値をリアルタイムに変更できます。画面中央をタップすると、新しい生命のタネ（Seed）を投下します。
* **デジタル虫かごシステム (Save & Load):** 
  本体の大容量フラッシュメモリ（FATFS）を利用し、気に入った模様をバイナリデータのまま一瞬で保存。ギャラリーモードでコレクションを閲覧できるだけでなく、過去の模様をロードして**その状態から培養を再開**することが可能です。
* **8種類のプリセット & 8種類のカラーテーマ:** 
  迷路、斑点、波紋など、パラメータ調整なしでも美しい相転移を楽しめます。

## 🛠 ハードウェア要件 (Hardware)

* **M5Stack STOPWATCH** (ESP32-S3, 16MB Flash, 8MB OPI PSRAM)

## 💻 開発環境と書き込み設定 (Environment & Settings)

本プログラムはメモリを極限まで使用するため、Arduino IDEでのコンパイル時に**厳密な設定**が必要です。設定を間違えると起動時にクラッシュ、または保存機能が動作しません。

### 必要なライブラリ
* `M5Unified` (M5Stack公式ライブラリ。依存関係の `M5GFX` 等もインストールしてください)
* `FFat` (ESP32標準ライブラリ)

### Arduino IDE ツール設定 (Tools Menu)
* **Board:** `ESP32S3 Dev Module` (または `M5Stack-StopWatch`)
* **USB CDC On Boot:** `Enabled`
* **Flash Size:** `16MB (128Mb)`
* **Partition Scheme:** `16M Flash (3MB APP/9.9MB FATFS)` **(重要: これ以外の設定では保存できません)**
* **PSRAM:** `OPI PSRAM` **(重要: これを有効にしないとメモリ不足でフリーズします)**

## 🎮 操作方法 (Controls)

本体左側のボタン（オレンジ）を「選択・送る」、右側のボタン（青）を「決定・アクション」として統一しています。

### 通常モード（シミュレーション中）
* **タッチ（左右のフチ上下）:** パラメータ (Feed / Kill) の手動調整
* **タッチ（画面中央）:** シード投下 (DROP SEED)
* **左ボタン（短押し）:** プリセットパターンの切り替え
* **右ボタン（短押し）:** カラーテーマの切り替え
* **左ボタン（長押し）＋ 右ボタン（クリック）:** メニューを開く

### メニューモード
* **左ボタン:** 項目の移動
* **右ボタン:** 決定
  * `SAVE CURRENT`: 現在の模様をフラッシュメモリに保存
  * `GALLERY`: 保存したコレクションの閲覧モードへ
  * `CLEAR ALL`: 全セーブデータを一括削除
  * `EXIT`: シミュレーションに戻る

### ギャラリーモード（デジタル虫かご）
* **左ボタン（短押し）:** 次の保存画像へ (NEXT)
* **左ボタン（長押し）:** 現在見ている画像を削除する (DELETE)
* **右ボタン（短押し）:** 閲覧を終了してメニューへ戻る (EXIT)
* **右ボタン（長押し）:** 現在見ている画像をロードし、その状態からシミュレーションを再開 (LOAD)
