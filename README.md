# Pocket Turing for M5Stack STOPWATCH
**〜 手のひらの上のデジタルテラリウム（Digital Bug Box） 〜**

M5Stack STOPWATCH（ESP32-S3搭載）の円形ディスプレイ上で、**チューリングパターン（Gray-Scottモデル）**をリアルタイムに演算・描画するインタラクティブ・ガジェットです。
直感的なタッチ操作で模様を育て、デジタル虫かごに採取し、PCへエクスポートできるほか、放置しておくだけで1時間ごとに環境が変化する「自動テラリウム機能」を備えています。


## ✨ 特徴 (Features)

* **24時間の自律テラリウム (Autonomous Ecosystem):**
  放置しているだけで、内蔵タイマーにより**60分ごとに環境（プリセットとカラーテーマ）が自動で切り替わります**。8種類のプリセットと8種類のカラーが組み合わさり、24時間かけてゆっくりと移り変わる生態系を観察できます。★ 現在：3分ごとに設定変更されています。
* **厳選された8つの環境パラメーター (Tuned Presets):**
  迷路（MAZES）、斑点（SPOTS）などの基本パターンに加え、細胞壁（CELLS）、指紋（FINGER）、ハイブリッド（HYBRID）など、美しく安定するよう特別に微調整された8つの独自の環境パラメーターを搭載しています。
* **有機的＆直感的なシード投下 (Smart Seeding):**
  環境変化時は画面全体に大小の細胞をばらまく「全体散布」を行い、手動で画面をタップした際は「指を置いた座標ピンポイント」から細胞が増殖する、2つのシード投下アルゴリズムを搭載。
* **デジタル虫かごシステム (Save, Load & Delete):** 
  マイコン内蔵フラッシュメモリ（LittleFS）を利用し、気に入った模様を保存。ギャラリーモードでコレクションを閲覧・整理（個別削除）できるだけでなく、過去の模様をロードして**その状態から培養を再開**することが可能です。*(※保存容量のストッパー付き：最大15個体)*
* **Wi-Fi画像エクスポート機能 (Export to PC):** 
  本体をWi-Fiアクセスポイント化し、PCやスマホのWebブラウザから無線で保存したBMP画像（デジタル標本）にアクセス・ダウンロードできます。
* **スマートバッテリー警告 (Low Battery Alert):**
  没入感を損なわないよう普段はUIを隠しつつ、バッテリー残量が10%を切った時のみ、画面下部に赤字で「LOW BATTERY」が点滅して危機を知らせます。

## 🛠 ハードウェア要件 (Hardware)

* **M5Stack STOPWATCH** (ESP32-S3, 4MB Flash, 8MB OPI PSRAM)

## 💻 開発環境と書き込み設定 (Environment & Settings)

本プログラムはメモリを極限まで使用し、内部ファイルシステムを構築するため、Arduino IDEでのコンパイル時に**厳密な設定**が必要です。設定を間違えると起動時にクラッシュするか、保存機能が動作しません。

### 必要なライブラリ
* `M5Unified` (M5Stack公式ライブラリ)
* `LittleFS`, `WiFi`, `WebServer` (ESP32標準ライブラリ)

### Arduino IDE ツール設定 (Tools Menu)
* **Board:** `ESP32S3 Dev Module` (または `M5Stack-StopWatch`)
* **USB CDC On Boot:** `Enabled`
* **Flash Size:** `4MB (32Mb)`
* **Partition Scheme:** `Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS)` **(重要: これ以外の設定ではLittleFSが正しく確保されません)**
* **PSRAM:** `OPI PSRAM` **(重要: これを有効にしないとメモリ不足でフリーズします)**

*(※初回書き込み後の起動時は、LittleFSの初期フォーマットが行われるため、画面が真っ暗なまま数十秒かかります。電源を切らずにお待ちください)*

## 🎮 操作方法 (Controls)

本体左側のボタン（オレンジ）を「選択・送る」、右側のボタン（青）を「決定・アクション」として統一しています。

### 通常モード（シミュレーション中）
* **放置:** 60分経過するごとに、自動で新しい模様・カラーに切り替わります。
* **タッチ（左右のフチ上下）:** パラメーター (Feed / Kill) の手動チューニング
* **タッチ（画面中央）:** タップした位置に新たな生命のタネを投下 (DROP SEED)
* **左ボタン（短押し）:** プリセットパターンの手動切り替え
* **右ボタン（短押し）:** カラーテーマの手動切り替え
* **左ボタン（長押し）＋ 右ボタン（クリック）:** メニューを開く

### メニューモード
* **左ボタン:** 項目の移動
* **右ボタン:** 決定
  * `SAVE CURRENT`: 現在の模様をフラッシュメモリに保存（上限15匹）
  * `GALLERY`: 保存したコレクションの閲覧モードへ
  * `EXPORT TO PC`: Wi-Fi接続による画像書き出しモードへ
  * `CLEAR ALL`: 全セーブデータを一括削除
  * `EXIT`: シミュレーションに戻る

### ギャラリーモード（デジタル虫かご）
* **左ボタン（短押し）:** 次の標本画像へ (NEXT)
* **左ボタン（長押し）:** 現在見ている標本を削除する (DELETE)
* **右ボタン（短押し）:** 閲覧を終了してメニューへ戻る (EXIT)
* **右ボタン（長押し）:** 現在見ている標本をロードし、その状態から培養を再開 (LOAD)

### エクスポートモード（PCへの書き出し）
1. メニューから `EXPORT TO PC` を選択。
2. PCやスマホから、Wi-Fiネットワーク **`BugBox`** (パスワード: `12345678`) に接続。
3. Webブラウザで **`http://192.168.4.1/`** にアクセスし、画像をダウンロード。
4. **左ボタン** を押して通常モードへ戻る。
